# Gardener Guidance

## Review conventions

- This repository is a safe test target for the Gardener GitHub App.
- Be explicit that reviews and issue comments are automated.
- Prefer structured review output with headings and bullets.
- Do not ask the author to confirm values that are visible in `.github/gardener.yml` or the diff.

## Testing expectations

- For config-only changes, verify behavior by triggering the GitHub App webhook and inspecting logs/output.
- Do not suggest package, runtime, or publishing changes unless the diff touches package metadata.

## Known false positives

- `liveMode: true` in this test repo is intentional for exercising GitHub write paths.
- Mutating actions are still constrained by the app installation and repo config.
